# 🚆 Techsaksham Train Information System

> A smart Python-based Train Information System that provides real-time train schedules, running status, station details, and route information using railway APIs.

---

# 🌐 Overview

The **Techsaksham Train Information System** is a CLI + Web application developed using Python that helps users access accurate and real-time railway information quickly and efficiently.

Whether you're a traveler checking train timings or a developer exploring API integration, this project provides a clean and informative platform to retrieve train data.

---

## ✨ Features

✅ Real-time train running status  
✅ Search trains using train number or name  
✅ Detailed train route & station information  
✅ Arrival and departure timings  
✅ CLI-based quick access system  
✅ Flask-powered web interface  
✅ Easy-to-understand UI output  
✅ API-based live railway data integration

# ⚙️ Installation Guide

## 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/Techsaksham-Train-System.git
```

## 2️⃣ Navigate to Project Folder

```bash
cd Techsaksham-Train-System
```

## 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

## 4️⃣ Run Application

```bash
python app.py
```
